# Right to Speak / Право голоса

Компактный модуль для Foundry VTT 14. Игроки отправляют обычные и срочные заявки мастеру, уточняют тип действия, цель и комментарий. Мастер ведёт очередь и отмечает «Увидел», «Дать слово» и «Закрыть». Игроки также могут отправлять друг другу личные обращения.

**Версия:** 0.2.0 BETA. Проверена в Foundry VTT 14.364.

## Установка

В Foundry откройте **Add-on Modules → Install Module** и укажите постоянный Manifest URL:

`https://raw.githubusercontent.com/Jerrvik/right-to-speak/main/src/right-to-speak/module.json`

Либо распакуйте [right-to-speak.zip](https://github.com/Jerrvik/right-to-speak/releases/download/v0.2.0-beta.3/right-to-speak.zip) в `{UserData}/Data/modules/`. Итоговый путь — `{UserData}/Data/modules/right-to-speak/module.json`. Включите модуль в мире. Для адресной доставки игрокам необходимо штатное разрешение Foundry **Query Users**.

## Использование

- **Слово → Поднять руку** отправляет обычную заявку.
- **Вмешаться** открывает четыре типа срочной заявки. Выбор типа сам по себе ничего не отправляет; укажите цель и комментарий при необходимости, затем нажмите **Отправить срочную заявку**.
- Значок замка в форме включает режим **Только мастеру** до отправки. Текст комментария виден автору и мастеру даже у публичной заявки.
- Значок конверта открывает личное обращение подключённому игроку. Получатель может ответить «Увидел»; последние обращения доступны в локальной истории.
- Панели перетаскиваются за заголовок и сворачиваются. Меню **⋯** содержит звук, уменьшение анимации и выбор отображения имени игрока или назначенного персонажа. Если персонажа нет, показывается имя игрока.

## Ограничения BETA

Скрытые заявки и личные обращения доставляются адресными запросами Foundry `User.query`, без широковещательного модульного сокета. Полные данные хранятся локально в IndexedDB соответствующих браузерных профилей. Очистка данных браузера или переход мастера на другой компьютер может лишить доступа к истории скрытых заявок. Рекомендуется испытать модуль в тестовом мире и сохранить резервную копию User Data перед использованием в основной кампании.

The interface is available in Russian and English. This beta targets Foundry VTT 14 and was tested on build 14.364. Private history is stored in each participant’s browser profile and does not move to another device automatically.
