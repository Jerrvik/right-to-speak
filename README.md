# Right to Speak / «Право голоса» — BETA

Модуль для Foundry VTT 14.364. Игрок одной кнопкой просит слово или сразу заявляет срочное вмешательство. Мастер видит очередь и может подтвердить просмотр, дать слово, завершить заявку или очистить очередь. Реализация системно независима.

**Статус конфиденциальности:** адресный протокол проверен по коду установленной Foundry 14.364, но не испытан в трёх независимых клиентах. До проверки GM + Алиса + Боб модуль и режим «Только мастеру» остаются BETA. Не используйте скрытые заявки для сведений, раскрытие которых недопустимо, до прохождения плана `tests/PRIVACY_V14_MANUAL_RU.md`.

Утверждённое ТЗ 3.1 находится в `docs/ТЕХНИЧЕСКОЕ_ЗАДАНИЕ_RU.md`. Архитектура и ограничения описаны в `docs/ARCHITECTURE_BETA_RU.md`.

## Установка

1. Остановите Foundry и создайте резервную копию User Data тестового мира.
2. В Foundry 14.364 откройте **Setup → Add-on Modules → Install Module** и вставьте в поле **Manifest URL** адрес `https://raw.githubusercontent.com/Jerrvik/right-to-speak/main/src/right-to-speak/module.json`.
3. Установите модуль и включите **Right to Speak — BETA** в тестовом мире.
4. Убедитесь, что обычные игроки имеют штатное разрешение **Query Users** (`QUERY_USER`). Модуль сообщит об ошибке доставки, если оно выключено.
5. Проведите ручной тест конфиденциальности до использования в основной кампании.

Для ручной установки можно скачать [right-to-speak.zip](https://github.com/Jerrvik/right-to-speak/releases/download/v0.1.0-beta.1/right-to-speak.zip) и распаковать его в `{UserData}/Data/modules/`. В архиве должен получиться путь `right-to-speak/module.json`.

Исходники устанавливаемого пакета находятся в `src/right-to-speak/`. Сборка: `npm run build`; автотесты: `npm test`. Внешние runtime-зависимости не нужны. Порядок публикации следующих версий описан в `docs/RELEASING_RU.md`.

## Игроку

- Панель можно перетащить за заголовок, свернуть кнопкой «−» и вновь развернуть. Положение сохраняется отдельно для каждого пользователя в данном браузере.
- До отправки включите «Только мастеру», если намерение должно быть скрытым. Переключатель виден рядом с основными кнопками.
- «Слово» отправляет обычную заявку. «Вмешаться» немедленно отправляет срочную заявку; после подтверждения можно выбрать тип, цель и комментарий.
- Повторное нажатие открывает текущую заявку. Изменение срочности обычной заявки требует подтверждения. Комментарий (до 240 символов) видят автор и GM, даже когда сама заявка публична.
- При недоставке повторите отправку: тот же локально сохранённый ключ не создаст второй запрос у мастера. При отсутствии GM кнопки недоступны.
- Звук выключен по умолчанию. Локальные опции панели позволяют включить звук и уменьшить анимацию; звук также должен быть разрешён в настройках мира.

## Мастеру

- Отдельная панель показывает срочные заявки выше обычных. Раскройте строку для комментария и действий «Увидел», «Дать слово», «Завершить».
- Фильтр меняет только отображение. «Очистить очередь» требует подтверждения и закрывает все активные заявки.
- Настройки мира: показ публичной очереди игрокам, лимит завершённой истории, интервалы против спама, разрешение звука. Они не содержат тайных данных.
- Скрытые заявки находятся в IndexedDB браузерного профиля GM. Обновление страницы в том же профиле восстанавливает их. Смена компьютера, очистка данных браузера и потеря всех локальных копий могут уничтожить закрытую очередь. Кнопка удаления локальных секретных данных находится в панели GM.
- При нескольких GM координатор выбирается по ID из активных пользователей с ролью Game Master; другим GM отправляются адресные копии. Одновременные вкладки одной учётной записи и переход координатора во время сетевого сбоя требуют ручной проверки; атомарной транзакции ядра Foundry нет.
