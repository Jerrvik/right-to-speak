# Right to Speak / Право голоса

Компактный модуль для Foundry VTT 14. Игроки отправляют обычные и срочные заявки мастеру, уточняют тип действия, цель и комментарий. Мастер ведёт очередь и отмечает «Увидел», «Дать слово» и «Закрыть». Игроки также могут отправлять друг другу личные обращения.

**Версия:** `0.2.0-beta.4` для Foundry VTT 14.364.

## Установка

В Foundry откройте **Add-on Modules → Install Module** и вставьте постоянный [Manifest URL](https://raw.githubusercontent.com/Jerrvik/right-to-speak/main/src/right-to-speak/module.json):

`https://raw.githubusercontent.com/Jerrvik/right-to-speak/main/src/right-to-speak/module.json`

Для ручной установки скачайте [ZIP релиза beta.4](https://github.com/Jerrvik/right-to-speak/releases/download/v0.2.0-beta.4/right-to-speak.zip) и распакуйте его в `{UserData}/Data/modules/`. Итоговый путь — `{UserData}/Data/modules/right-to-speak/module.json`. Включите модуль в мире. Для адресной доставки игрокам необходимо штатное разрешение Foundry **Query Users**.

## Использование

- **Слово → Поднять руку** отправляет обычную заявку.
- **Вмешаться** открывает четыре типа срочной заявки. Выбор типа сам по себе ничего не отправляет; укажите цель и комментарий при необходимости, затем нажмите **Отправить срочную заявку**.
- Значок замка в форме включает режим **Только мастеру** до отправки. Текст комментария виден автору и мастеру даже у публичной заявки.
- Кнопка **Ответить** в карточке заявки отправляет текст автору. Ответ сохраняется в истории заявки, не меняет её статус; автор может подтвердить просмотр и ответить мастеру.
- Значок конверта открывает личное обращение подключённому игроку. Получатель может подтвердить просмотр или ответить; связанные сообщения отображаются по времени в локальной истории.
- Панели перетаскиваются за заголовок и сворачиваются в кнопку 40×40. Она показывает счётчик и остаётся перемещаемой. Меню **⋯** содержит звук, кнопку **Проверить звук**, уменьшение анимации и выбор отображения имени игрока или назначенного персонажа. Если персонажа нет, показывается имя игрока.

## Ограничения BETA

Скрытые заявки, ответы и личные обращения доставляются адресными запросами Foundry `User.query`, без широковещательного модульного сокета и общих настроек мира. Полные данные хранятся локально в IndexedDB соответствующих браузерных профилей. Очистка данных браузера или переход мастера на другой компьютер может лишить доступа к истории скрытых заявок и ответов. Сеть проверена в трёх клиентах локального стенда V14.364; это не гарантирует конфиденциальность в каждой установке. Перед основной кампанией проверьте приватность на своём сервере и сохраните резервную копию User Data. Физическая слышимость звука через устройство GM требует проверки человеком; на стенде подтверждён только успешный запуск воспроизведения браузером.

The interface is available in Russian and English. This beta targets Foundry VTT 14 and was tested on build 14.364. Private history is stored in each participant’s browser profile and does not move to another device automatically.
