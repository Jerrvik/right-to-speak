# Ручной тест конфиденциальности Foundry 14.364 — НЕ ПРОВЕДЁН

Стенд: тестовый мир Foundry 14.364, три независимых профиля браузера GM, Алиса, Боб; дополнительно второй GM. Открыть у Боба DevTools Network → WS frames, Elements, Application → IndexedDB/Local Storage, Console. Зафиксировать версию модуля и скриншоты/сетевые логи каждого шага. Не выполнять на основной кампании до резервной копии User Data.

| ID | Действие | Условие PASS |
|---|---|---|
| P01 | Алиса включает «Только мастеру», отправляет срочную заявку с целью Боб и уникальным комментарием | В кадрах WS, DOM, storage, `game.settings` и начальной загрузке Боба нет ID, текста, факта или счётчика заявки. GM и Алиса видят её. |
| P02 | Боб обновляет страницу и переподключается | Тайные данные всё ещё отсутствуют, в том числе в загрузке мира. |
| P03 | GM обновляет страницу в том же профиле с сохранённым IndexedDB | Тот же ID, время и статус заявки восстановлены. |
| P04 | GM нажимает «Увидел», «Дать слово», «Завершить» | Статусы меняются у Алисы и GM, но не появляются ни в одном канале Боба. |
| P05 | Алиса подтверждает private→public | Только после подтверждения появляется публичная проекция без комментария и без пропусков порядка. |
| P06 | Алиса подтверждает public→private | Видно предупреждение; после перехода дальнейшие статусы/комментарии не передаются Бобу. |
| P07 | Боб вызывает `game.users.get(gmId).query("right-to-speak.command", payload)` с поддельными `isGM`, `ownerUserId`, ревизией | GM-команда и правка чужой заявки отклоняются по серверно переданному `context.user`. |
| P08 | Два GM одновременно меняют один ID; затем координатор отключается | Есть один принятый переход, конфликтующие клиенты обновляют снимок; остаточное расхождение документируется как дефект. |
| P09 | Алиса пять раз быстро нажимает «Слово», теряет ответ, повторяет с тем же ID | В очереди одна запись, второй запрос возвращает её состояние. |
| P10 | Все GM уходят offline | Кнопки недоступны, недоставленная заявка не получает статус `pending`. |
| P11 | Вставить HTML и 240+ символов; ник 40+ символов; zoom 200%; reduced motion | HTML показывается текстом; длина ограничена; кнопки доступны; срочная анимация отсутствует при reduced motion. |

Если у Боба есть любой приватный payload или метаданные P01–P04: **FAIL / выключить режим «Только мастеру» и не выпускать как защищённый**. После проверки записать для каждой строки фактический результат PASS/FAIL и доказательство. Пока все строки имеют статус **NOT TESTED**.
